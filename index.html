☁️ Sincronização em Nuvem
Como configurar:
Siga o guia PLANILHA / 2_GUIA_PASSO_A_PASSO.md:
1. Limpar os dados da planilha copiada
2. Trocar o token no Apps Script
3. Implantar como "App da Web" → Qualquer pessoa
4. Colar aqui embaixo a URL (termina em /exec) e o token

Senha secreta que protege teus dados na nuvem. Cole o mesmo token que está no script (.gs). Fica salvo só neste aparelho.

⬆️ Enviar = manda DESTE aparelho pra nuvem
⬇️ Baixar = traz a nuvem pra ESTE aparelho
